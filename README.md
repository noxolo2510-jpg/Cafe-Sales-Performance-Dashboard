# Cafe-Sales-Performance-Dashboard
An interactive Cafe Sales Performance Dashboard built in Microsoft Excel to analyse revenue, product performance, transactions, payment methods, locations and sales trends.

Monthly Revenue Trend



Key Insights

Smoothie generated the highest revenue.

Sandwich was the second-highest revenue-generating product.

Coffee recorded one of the highest transaction volumes.

Sales were made using Cash, Credit Card and Digital Wallet.

Unknown values were identified across multiple dataset fields, highlighting data-quality and completeness issues.

 
Data Quality

The dataset contained missing or Unknown entries in several fields, including Item, Payment Method, Location and transaction date-related fields. These were identified as data-quality issues during the analysis.


Project Objective

To demonstrate practical Excel data analysis skills by transforming raw cafe sales data into an interactive dashboard that supports business decision-making.
